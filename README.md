## Featured projects

### Global Payments Performance · Power BI

**A portfolio report built with synthetic, anonymized data.** It brings processor performance, payment fees, savings opportunities, and network incentives into four connected views.

![Global Payments Performance Executive Overview](Global%20Payments%20Executive%20Overview.png)

| Report page | Questions it helps answer |
| --- | --- |
| Executive Overview | How are the key payment measures trending? |
| Processor Performance | Which processors warrant a closer look at volume, approvals, fees, or invoice variance? |
| Fee Optimization | How do expected and realized savings compare across initiatives? |
| Network Incentives | How does qualifying volume compare with targets, and which records qualify? |

**What I built:** I cleaned, merged, and appended queries in Power Query; modeled the data with shared dimensions; created DAX measures and time-based comparisons; and added synced slicers, a dynamic trend, a custom tooltip, processor drillthrough, and mobile layouts. I checked filter behavior, drillthrough, and refresh. After initial layout feedback, I adjusted fonts, wrapping, and visual dimensions across the pages myself to make the report easier to read.

> The report's numbers are illustrative. The project demonstrates my technical approach and is separate from the results of my professional work below.
